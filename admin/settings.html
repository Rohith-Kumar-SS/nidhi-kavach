Demo clock

Danger zone: reset demo data

Puts the portal back to the original demo story. Use it before a fresh presentation.

  • Every FDR, release, discrepancy, notification and audit entry is deleted and generated again.
  • All users are recreated with the demo password, so you will be signed out.
  • Bank and portal signing keys are re-issued and the demo clock returns to today.
  • It takes up to a minute. It cannot be undone.
